# Example image sources

Synthetic low-light images generated by `scripts/make_examples.py` from scikit-image 0.26.0 sample data. The licence of each source photo is as stated in the scikit-image documentation for that image. No dataset images (LOL, LOL-v2) or personal photos are redistributed.

| File | Source | Licence of source image | Low-light simulation |
|---|---|---|---|
| `coffee_dark.jpg` | `skimage.data.coffee()` | CC0 - photographer Rachel Michetti (no copyright restrictions) | exposure x0.08, uniform illumination, Poisson-Gaussian noise (read sigma 0.004) |
| `chelsea_extremely_dark.jpg` | `skimage.data.chelsea()` | CC0 - photographer Stefan van der Walt (no copyright restrictions) | exposure x0.025, uniform illumination, Poisson-Gaussian noise (read sigma 0.006) |
| `astronaut_uneven_light.jpg` | `skimage.data.astronaut()` | Public domain - NASA (no known copyright restrictions) | exposure x0.1, side illumination, Poisson-Gaussian noise (read sigma 0.004) |
| `rocket_night_highlights.jpg` | `skimage.data.rocket()` | Public domain - SpaceX photos released into the public domain | exposure x0.12, uniform illumination, Poisson-Gaussian noise (read sigma 0.004) |
